프로젝트 개요

IoT기획팀이 매일 반복적으로 사용하는 Gmail, Google Sheets, Jira, Confluence, Google Drive를 단일 터미널 명령어로 통합 제어하는 AI Native 자동화 허브를 구축했다. 이 시스템은 터미널 환경에서뿐만 아니라 Claude Code, Cursor, AntiGravity 같은 AI IDE에서도 동일하게 호출되어, 팀원 누구나 자신이 쓰는 개발 환경에서 같은 자동화 파이프라인을 사용할 수 있다.

핵심 철학은 "조종사(Pilot)" 메타포다. 비행기 조종사가 하나의 콕핏(Cockpit)에서 수십 개의 계기판을 동시에 제어하듯, 개발자·기획자가 터미널 하나에서 Gmail 수신함·Jira 보드·Confluence 위키·Google Sheets 데이터를 실시간으로 조작하고 AI 자동응답을 실행한다.

연결된 6개 서비스 (Cockpit Map)

📧 Gmail
수신 메일 AI 분류, 라벨 자동 적용, 발송 자동화. gws gmail messages list로 CLI에서 바로 조회.
📊 Google Sheets
분류된 데이터를 실시간 적재. WQA 인증현황·이슈 트래킹이 자동으로 시트에 기록됨.
🎫 Jira
신규 QA Inquiry 이슈 감지 → Claude API 응답 초안 → 자동 댓글 또는 담당자 메일. 평균 응답 2분.
📚 Confluence
회의록·정의서 AI 요약 후 자동 게시. MCP Confluence 연동으로 Claude가 직접 페이지를 생성·수정.
🤖 Claude / Cursor
IDE 내 터미널에서 동일 CLI 파이프라인 호출. 코드 컨텍스트와 결합해 더 정확한 자동응답 생성.
⚡ AntiGravity
사내 AI 플랫폼. 동일 gws 명령어로 연동, 팀원들이 UI 없이 터미널에서 AG 파이프라인 실행.

자동화 파이프라인 (End-to-End)

수신 메일 → Gmail API 조회 → Claude AI 분류 (카테고리·담당자·우선순위)
→ Jira 이슈 자동생성 → Claude 응답 초안 → 자동 댓글
→ Google Sheets 기록 → WQA 대시보드 실시간 반영 → 알림 발송

기술 스택 및 명령어

GWS CLI 핵심 명령어

# 인증
gws auth login --account asderio@coway.com -s gmail,sheets

# Gmail 동기화
npm run wqa:gws:sync # 실제 적재
WQA_DRY_RUN=1 npm run wqa:gws:sync # 드라이런 테스트

# Sheets 데이터 조회
gws sheets spreadsheets values get --params '{"spreadsheetId":"...","range":"A1:E20"}'

# Jira 이슈 처리 (MCP)

# mcp__mcp-atlassian__confluence_create_page 직접 호출

IoT기획팀 AI Native 철학

연결 가능한 모든 것은 연결한다

IoT기획팀은 2026년부터 "연결 가능한 모든 서비스를 AI로 묶어 팀 전체를 AI Native화"하는 방향으로 업무 환경을 전환하고 있다. GWS CLI & Jira Automation은 그 첫 번째 성과다.

  • 터미널 우선: 모든 반복 업무는 CLI 명령어 한 줄로 실행 가능하게 설계
  • IDE 동등: Claude Code·Cursor·AntiGravity 어디서든 동일 파이프라인 실행
  • 제로 수동: 판단이 필요한 업무만 사람이 처리, 나머지는 전부 자동화
  • 비용 제로: GWS 무료 티어 + Claude CLI + 오픈소스 조합으로 운영비 $0
